 ScamShield 

 An Explainable AI-Based Job and Internship Scam Detection System for Pakistani Students

 Project Overview

ScamShield is a proposed AI-powered web application designed to help Pakistani students, fresh graduates, and job seekers identify potentially fraudulent job and internship advertisements.

The system will analyze advertisement text using machine learning techniques and highlight suspicious patterns to help users make more informed decisions.

  Problem Statement

Online job seekers may encounter fraudulent advertisements involving advance payment requests, unrealistic salary promises, fake recruitment opportunities, and misleading job descriptions. ScamShield aims to provide an accessible tool for assessing potential risks in such advertisements.

 Planned Features

* Analyze pasted job and internship advertisements.
* Classify advertisements as potentially legitimate or suspicious.
* Highlight suspicious words and warning signs.
* Display an understandable explanation of the assessment.
* Provide a simple, user-friendly web interface.

 Technologies

* Programming Language: Python
* Machine Learning: Scikit-learn
* Text Processing: NLTK
* Data Analysis: Pandas
* Web Application: Streamlit
* Model Storage: Joblib
* Version Control: Git and GitHub

 Project Objectives

1. Develop a web-based job advertisement screening system.
2. Prepare a labeled dataset for machine learning.
3. Train and evaluate text classification models.
4. Identify and explain suspicious advertisement patterns.
5. Promote scam awareness among students and job seekers.

 Project Status

Currently in the proposal and initial setup phase. Implementation, model training, testing, and evaluation are planned future activities.

 Disclaimer

ScamShield will provide preliminary risk assessments, not definitive verification of an advertisement's authenticity. Users should independently verify employers and never pay suspicious recruitment fees.
